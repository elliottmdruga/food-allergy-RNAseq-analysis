# Food Allergy RNAseq Analysis

This repository contains the code for my RNA Sequencing data analysis of individuals with single and multi-food allergies. This was done as the final project for BINF-5240 at Georgetown University.

## Data Source

Data for this project originated from the study "Immuno-epigenomic analysis identifies attenuated interferon responses in naïve CD4 T cells of adolescents with peanut and multi-food allergy", published in Pediatric Allergy and Immunology in 2022. The study can be found with PMID 36433861. The experimental data used for my own analyses originated from the study's GEO repository with accession GSE189149.
